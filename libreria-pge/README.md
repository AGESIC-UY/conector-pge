## Librería PGE-Client

Para el ejemplo de consumo de timestamp:


Build
mvn clean package o mvnw clean package si es windows.

Run
para ejecutarlo, desde la carpeta raíz del proyecto ejecutar
java -jar target\ejemplo-consumo-pdi-timestamp-1.0.0.jar
Ejemplo Salida:
SOAP Timestamp, respuesta: 2023-09-26T18:04:39.409Z
